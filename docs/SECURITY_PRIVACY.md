# SECURITY_PRIVACY

## Local-first
Sessões e strokes permanecem no dispositivo no MVP.

## Dados privados
A escrita pode conter nomes, assinaturas e texto pessoal. Não fazer upload automático.

## Regras
Consentimento explícito para IA/cloud; backup opt-in; credenciais no Android Keystore; logs sem conteúdo escrito por padrão; export somente por ação explícita; exclusão de sessão remove strokes e derivados conforme política.

## Assinatura
Prática de assinatura não promete autenticação, antifraude ou segurança biométrica.

## IA futura
Mostrar quais dados serão enviados; permitir features sem imagem/strokes quando possível; nunca enviar a biblioteca inteira por padrão.
